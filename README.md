# Line Damage Inspector

The recommended detector learns to filter residual components and refine their bounding boxes from the official 1,000-image-pair DeepPCB training split. It uses paired intensity and residual patches, two Extra Trees estimators and non-maximum suppression. Evaluation on the 500-image-pair test split localized 2,941 of 3,140 annotations at 93.99% precision and 93.66% recall (class-agnostic IoU > 0.33). The initial connected-component baseline localized 93. The test split was previously inspected during development and contains defective boards. Independent healthy-board false reject rates and factory acceptance are open.

Download the **pcb-inspector** artifact from a successful [hosted workflow](https://github.com/yakupakcy36/line-damage-inspector/actions/workflows/validate.yml). Extract the archive, open its directory and install the dependencies with `python -m pip install -r requirements.txt` in Python 3.12. Run `python learned.py predict pcb.skops reference.jpg inspected.jpg`. Training, serialization, reload parity and official test-set evaluation run on the hosted runner. Use artifacts from a trusted workflow run. The simple baseline below remains available for comparison.

Locate changes on a printed circuit board from a fixed overhead camera and a matching intact template. The inspector estimates translation, checks registration quality and compares binary copper patterns while tolerating one pixel of edge error. It returns candidate defect boxes in the inspected image's coordinates (right and bottom exclusive). A low registration score or displacement above eight pixels yields `uninspectable`.

Run `python inspection.py reference.jpg inspected.jpg` with NumPy 2.2.6 and headless OpenCV 4.12.0.88. No trained weights or API credentials are needed. Read `excluded_border_px` before interpreting a clear result: the border has no reliable template overlap. Rotation, different PCB designs and changing camera scale are outside this first version's scope.

GitHub Actions runs the synthetic regression tests and evaluates the official 500-image-pair [DeepPCB](https://github.com/tangsanli5201/DeepPCB) test split on a hosted CPU. Each run publishes class-agnostic precision and recall using greedy one-to-one matching at IoU > 0.33. Uninspectable pairs contribute missed annotations. DeepPCB includes manually added defects and its authors specify research use. The defective-board test split cannot estimate the false reject rate for healthy production boards. No dataset images are redistributed here.

DeepPCB image pairs are crops from larger scans. All seven training groups also occur in the official test split. No identical decoded reference or inspected images were found across the corresponding splits, and two test references had near matches in training. Five-fold validation holding out entire training groups gave 90.53% precision, 92.04% recall and 91.28% F1. The packaged group-validation.json contains the fold counts. CI checks grouped precision >= 89.5% and recall >= 91% (about one percentage point below the reference results).
